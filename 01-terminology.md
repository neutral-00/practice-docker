# Terminology

1. Docker File
- A text file with instructions to build and image
- In other words, you create an image using a docker file.

2. Image
- A single file with all the dependencies and libraries to run a program

3. Container
- A live instance of an image started by docker engine.
- In general, containers are an isolated environment to run any code.

4. Docker Registry
- A central repo for docker images
