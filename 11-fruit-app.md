# Fruit App (connect to local db)

## Proof of Concept
- [x] Connect to a local machine database from an app running in a docker container.

## App Idea
Before we build large applications, I have an idea an idea of a simple app named fruit-app. \
It will have a simple ui where user can add a new fruit. And see the list of fruits below it.

## Details
- User should be able to enter the below detials:
    - fruit name
    - upload a fruit image
    - description
- User should be able to see list of fruits
    - Fruits be collapsed by default but can be expanded to view the details
